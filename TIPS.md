# Tips — multi-roll entropy

- Prefer **independent slices** for independent faces; chain hashes only when order matters (shuffle).
- Cap slices at 8 for one 256-bit value (32 bytes).
- Related: [Fisher–Yates](https://github.com/pixel-journey/px-orng-fisher-yates-deck-shuffler), [dice](https://github.com/pixel-journey/px-orng-dice-multi-tier-payout).
